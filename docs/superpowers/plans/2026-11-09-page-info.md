# Page Info Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Page Info slice and window that loads a website in a hidden window, reads it, and shows the results as cards.

**Architecture:** A self-contained script reads the page in a private JavaScript world and returns plain data. The main process validates that data and runs Tuki's checks on it. `PageInfoController` holds the timing rules behind a small `SiteView` interface, so they are tested without Electron, and the Page Info window only draws the reports it is sent.

**Tech Stack:** Electron 45, React, Zustand, zod, vitest, jsdom (test only).

**Spec:** `docs/superpowers/specs/2026-11-09-page-info-design.md`

**Source of the copied code:** `C:\Users\ACER\Documents\Personal Projects\tuki-main\tuki-main`, by the same author.

## Global Constraints

- Read timing: when loading finishes, and again 1500 ms later. Load limit: 30000 ms.
- List limits: 50 items, headings 200, hreflang 100.
- Recommended lengths: title up to 60, description 50 to 160.
- User-facing text, verbatim: "Enter a web address, like example.com.", "Checking…", "Could not open that page.", "That page took too long.", "Could not read that page.", "Missing", "None found", "Showing 50 of 120" (with real numbers).
- Only `http` and `https` can load.
- Page data is untrusted: validated in the main process, shown only as React text, never linked.
- Partition: `persist:page-info`. Results are never saved.
- The repo has no commits and the user has not asked for any. Do not commit.
- Run single test files with `npx vitest run <path>`.

## Review Focus

- A page with a huge `data:` image or very long inline script must still produce a report, not "Could not read that page." Test in Task 2.
- A page with no `<head>` details must show "Missing" values, not fail. Test in Task 2.
- A copied address with spaces or a line break around it must still count; a sentence containing an address must not. Test in Task 3.
- A new check interrupting a load reports error code -3, which must not show "Could not open that page." Test in Task 4.
- Closing the window during a read must not send to a destroyed window. Test in Task 4.
