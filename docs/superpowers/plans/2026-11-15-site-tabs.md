# Site tabs: plan

Spec: `docs/superpowers/specs/2026-11-15-site-tabs-design.md`

1. **Extension** (`protocol.js`, `tabs.js`, `events.js`, `connection.js`, `background.js`): state per app tab id, the id on every action and event, `forget`, drop `activeTabChanged`. Tests alongside.
2. **Bridge and Chrome site** (`chrome-bridge.ts`, `chrome-site.ts`): events carry the id; a Chrome site sends its id and listens only to its own events. Tests alongside.
3. **Main** (`page-info-window.ts`, `page-info.ipc.ts`, preload, `types.ts`): one controller per app tab, the tab strip channel, new / close / switch IPC. Tests alongside.
4. **Window** (`page-info.store.ts`, `SiteTabs.tsx`, `PageInfoWindow.tsx`, `PageLinks.tsx`, `page-info.css`): the strip, per-tab state, Ctrl/middle-click on Open. Tests alongside.
5. `npm run typecheck`, `npm test`, `npm run lint`. Reload the extension in Chrome and try it in the real app.
