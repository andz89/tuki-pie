# Info Card: plan

Spec: `docs/superpowers/specs/2026-11-16-info-card-design.md`

1. **Extension**: `readActive` in `tabs.js` (active tab of the last focused normal window, http/https only, runs `collect-page.js`), `activeTabChanged` event in `events.js` (tabs.onActivated, windows.onFocusChanged, active tab load complete or address change), both added to `protocol.js`, wired in `background.js`, version bump. Tests alongside.

3. **Main**: `info-card/info-card-bounds.ts` (layout + work area to window bounds, tested), `info-card/info-card-reader.ts` (debounced read of the active tab into a report, tested), `windows/info-card-window.ts` (frameless, on top, closes on blur while unpinned), `info-card.ipc.ts` (state, set pin, set layout, set fields, image), channels, `info-card` role, preload.
4. **Renderer**: `info-card.html`, `InfoCard.tsx` (three layouts, pin, layout menu, field checklist, empty states), styles, test.
5. **Pie**: `Info Card` ring slice after Web Page, `info-card` icon, open action.
6. `npm run typecheck`, `npm test`, `npm run lint`; README note to reload the extension.
