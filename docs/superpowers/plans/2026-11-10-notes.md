# Notes slice: plan

Spec: `docs/superpowers/specs/2026-11-10-notes-design.md`

Each task ends with typecheck, lint and its tests passing.

1. **Reminder times** (`src/shared/reminder-time.ts` + tests): quick picks, `nextOccurrence`, `isDue`, the reminder wording.
2. **Schema and storage**: `note.schema.ts`, migration `006_notes.sql`, `NoteRepository` + tests.
3. **Service** (`NoteService` + tests): list, create, update, remove, set reminder, due notes, done, snooze, limits, empty notes not kept.
4. **Scheduler** (`ReminderScheduler` + tests): one timer to the next due time, capped at an hour; catch-up on start; `refresh()` after changes.
5. **Windows**: `notes-window.ts` (open or focus, open one note), `reminder-window.ts` (top-right card, `showInactive`, fits its height).
6. **IPC and preloads**: channels, `notes.ipc.ts` and `reminder.ipc.ts` with input checks + tests, `notes-preload.ts`, `reminder-preload.ts`, forge and vite entries.
7. **Notes window UI**: `notes.html`, `NotesWindow.tsx`, store, search, autosave, delete, reminder menu, CSS.
8. **Reminder card UI**: `reminder.html`, `ReminderCard.tsx`, CSS.
9. **Donut**: ring item, `NOTES_INDEX`, `openNotes`, window IPC, tests.
10. **Wire up in `main.ts`**, README section, full test run.
