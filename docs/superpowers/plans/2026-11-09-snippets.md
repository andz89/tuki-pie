# Snippets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the placeholder Snippets slice into a working feature: saved text shown as circles, copied to the clipboard on click, managed from the donut and Settings.

**Architecture:** A new `snippets` table, repository and service in the main process, following Shortcuts. The donut and Settings talk to it through zod-validated IPC. Decisions a test can reach live in small pure modules, because the repo tests stores and helpers, not rendered components.

**Tech Stack:** Electron, React, Zustand, better-sqlite3, zod, vitest.

**Spec:** `docs/superpowers/specs/2026-11-09-snippets-design.md`

## Global Constraints

- At most 8 snippets. Name up to 24 characters. Text up to 10,000 characters.
- Blank means only spaces or line breaks, and a blank name or text is refused.
- Copying sends an id. The text always comes from the database, and is copied exactly.
- User-facing errors, verbatim: "You can save 8 snippets at most.", "That snippet no longer exists.", "Could not copy that snippet.", "The snippets changed. Please try again."
- The pinned-donut notice reads "Copied" and lasts 1200 ms.
- The repo has no commits and the user has not asked for any. Do not commit.
- Run single test files with `npx vitest run <path>`.

## Review Focus

- Text with line breaks, tabs, surrounding spaces and emoji must reach the clipboard unchanged. Test in Task 1.
- A name of only spaces must be refused, even though `.min(1)` would pass it. Test in Task 1.
- The clipboard writer throwing must give a readable message, not a generic failure. Test in Task 1.
- Two quick copies on a pinned donut: the first timer must not end the second notice early. Test in Task 3.
- A `snippet-edit` request for a removed snippet must report the problem instead of opening an empty form. Test in Task 5.

```ts
it('copies the stored text exactly', () => {
  const content = '  first\r\n\tsecond 😀  ';
  const [saved] = service.add({ label: 'A', content });
  service.copy(saved.id);
  expect(writeClipboard).toHaveBeenCalledExactlyOnceWith(content);
});
it('refuses a ninth snippet', () => {
  for (let n = 0; n < 8; n += 1) service.add({ label: `S${n}`, content: 'x' });
  expect(() => service.add({ label: 'S9', content: 'x' })).toThrow(
    new UserError('You can save 8 snippets at most.'),
  );
});
it('explains a failed copy', () => {
  const [saved] = service.add({ label: 'A', content: 'x' });
  writeClipboard.mockImplementationOnce(() => {
    throw new Error('busy');
  });
  expect(() => service.copy(saved.id)).toThrow(
    new UserError('Could not copy that snippet.'),
  );
});
```

Also: `copy`, `update` and `remove` of an unknown id throw `UserError('That snippet no longer exists.')`. `add` appends with `position` equal to the old count. `update` changes label and content. `remove` closes the gap, so positions read 0, 1. `reorder` applies a valid order, and throws `UserError('The snippets changed. Please try again.')` for a missing id, an extra id, or a duplicate.
